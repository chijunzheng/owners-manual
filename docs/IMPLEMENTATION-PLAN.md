## Process notes

- Codex gate: clean PRs signal via a 👍 reaction from `chatgpt-codex-connector[bot]` on the PR body — check reactions, not just review comments.
- Merge sequentially and re-check mergeability after EACH merge: parallel-branch lockfile/tsconfig-references conflicts appear only once a sibling lands (hit on PR #28; resolved by unioning `tsconfig.json` references and `pnpm install --lockfile-only` regeneration).
- Worktree cleanup ordering: `git worktree remove --force <path> && git worktree prune` must complete before `git branch -D` succeeds — `gh pr merge --delete-branch` cannot delete a branch a worktree still holds.
- `corpus-intrinsic` CI job (merge-to-main + nightly) fetches only `rta-2006` (`--only` flag) so drift in unrelated sources — the rent-guideline currency micro-source especially — cannot mask as a parser regression. Per-PR coverage stays network-free via golden + fixture asserts.
